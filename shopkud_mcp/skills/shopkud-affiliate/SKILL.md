# คัดสินค้า Affiliate ด้วย ShopKud

อ่าน [วิธีทำงานและตัวอย่าง](references/workflow.md) เมื่อเริ่มงานคัดสินค้าโดยใช้คู่มือรุ่นนี้ ใช้หลักฐานและข้อจำกัดจากผลเครื่องมือเป็นหลัก ไม่ต้องอ่านคู่มือเต็มซ้ำต่อสินค้า

- เริ่มจากสินค้าที่เจ้าของกำหนดและประโยชน์ต่อผู้ซื้อ อย่าเปลี่ยนสินค้าหรือกลยุทธ์แบรนด์เอง
- งานคัดตามค่าคอมใช้ `rank_affiliate_products` เป็นค่าเริ่มต้น ให้โค้ดสแกน กรอง ตรวจค่าคอมตามช่องทาง และจัดอันดับในคำสั่งเดียว งานพร้อมกันจะต่อคิวและใช้ผลเดียวกัน
- ใช้ `scan_products` และ `get_scan_products` เฉพาะงานค้นแบบกำหนดเองที่ playbook ยังครอบคลุม ไม่สแกนซ้ำเพื่ออ่านสินค้าเดิม
- ใช้ `get_product_detail(view="brief")` ตรวจรุ่น/ตัวเลือก ร้าน และค่าคอมเฉพาะช่องทาง เพิ่มข้อมูลเต็มเมื่อจำเป็นต้องตรวจภาพหรือหลักฐานเพิ่มเติม
- ตรวจความน่าเชื่อถือของร้านและข้อมูลการซื้อก่อนจัดอันดับด้วยค่าคอม แยกสิ่งที่เห็นจริง การคำนวณ และข้อมูลที่ยังไม่ทราบ
- ก่อนรับลิงก์ ตรวจ `get_product_history` และประสานงานกับเอเจนต์อื่น ใช้ลิงก์ที่บันทึกไว้แล้วเมื่อยังเหมาะสม การขอรับลิงก์ใหม่ต้องอยู่ในคำสั่งเจ้าของ และไม่ทำซ้ำเมื่อผลไม่แน่นอน
- เก็บตัวเลือกเฉพาะแบรนด์ บุคลิกตัวละคร และรายการที่เจ้าของอนุมัติไว้ในโปรเจกต์ของเจ้าของ ไม่เปลี่ยนให้เป็นกฎทั่วไปของสกิลนี้

ถ้าอ่านผ่าน MCP แทนไฟล์ ใช้ `get_workflow_guide(view="full")`; `view="brief"` คืนรุ่นและแผนที่เครื่องมือโดยไม่ส่งคู่มือเต็ม ไม่แก้การตั้งค่าเอเจนต์หรือติดตั้งสกิลให้อัตโนมัติ
