อ่านหน้าสินค้าสาธารณะ

Chrome จะให้สิทธิ์อ่านเว็บไซต์ shopee.co.th ทั้งโดเมน และใช้ scripting แต่ ShopKud จะทำงานเฉพาะหน้าสินค้า /product/ร้าน/สินค้า ที่ระบุผ่านเครื่องมือเท่านั้น

ไม่อ่านบัญชี คุกกี้ ประวัติ หรือ API ลับ ไม่ซื้อสินค้า ไม่เลือกตัวเลือกสินค้า ไม่รับแท็บที่คุณเปิดเองมาเปลี่ยนหน้า

กำลังตรวจสิทธิ์…

วิธีอ่านข้อมูลสินค้า

ช่วยให้ Shopee โหลดชื่อร้านและคะแนนก่อนอ่าน เปิดเป็นค่าเริ่มต้น ใช้เฉพาะแท็บที่ ShopKud สร้าง แล้วกลับแท็บเดิมเมื่อเสร็จ หากคุณสลับแท็บเอง ShopKud จะไม่แย่งกลับ ไม่ซื้อหรือเลือกตัวเลือกสินค้า

ปิดตัวเลือกนี้เพื่อทำงานเบื้องหลังเท่านั้น แต่ข้อมูลร้านหรือคะแนนอาจโหลดไม่ครบ ไม่ต้องเปิด Remote debugging หรือติดตั้ง DevTools
